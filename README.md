# System Software Toolchain

A C++ implementation of a small system-software toolchain consisting of an assembler, linker, and CPU emulator.

The project implements the main mechanisms involved in translating assembly programs into relocatable object files, linking multiple object files into executable images, and executing the resulting machine code on an emulated processor.

## Components

### Assembler

The assembler processes assembly source code and generates relocatable object files.

Implemented functionality includes:

* Lexical analysis and parsing using Flex and Yacc
* One-pass assembly
* Sections
* Instruction encoding
* Symbol and macro tables
* Forward-reference resolution
* Relocation entry generation
* Assembly directives including `.section`, `.global`, `.extern`, `.word`, `.skip`, `.ascii`, and `.equ`
* Expression evaluation
* ELF-like object-file generation (sections, symbols, string, and relocation information)

### Linker

The linker combines relocatable object files into linked images.

Implemented functionality includes:

* Object-file parsing
* Section merging and placement
* Symbol resolution
* Multiple-definition and unresolved-symbol detection
* Relocation processing
* Generation of relocatable and executable output images


### CPU Emulator

The emulator executes the machine code generated by the toolchain on a software-defined CPU.

Implemented functionality includes:

* Instruction fetch/decode/execute cycle
* Register file and program counter
* Arithmetic, logical, branch, load/store and call instructions
* Software and hardware-style interrupts
* Timer and terminal emulation
* Memory-mapped I/O

The CPU executes instructions until `HALT`, while periodically polling the emulated terminal and timer and checking for pending interrupts.

### Memory System

The emulator implements a dynamically allocated paged memory model.

It provides:

* Dynamic page creation
* Loading program images into memory
* Detection of accesses to uninitialized memory
* Memory-mapped terminal I/O
* Memory-mapped timer configuration


## Object-File Format

The project defines an ELF-like object-file representation containing:

* File headers
* Section information
* Section-name string tables
* Symbol and string tables
* Relocation information

The assembler serializes these structures, while the linker parses and processes them during linking.
